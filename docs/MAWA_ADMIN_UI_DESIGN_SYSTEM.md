# MAWA Admin Console Visual Design System

The Admin Console now shares the same professional MAWA visual language as the ERP application.

## Review scope

- 7 Admin screen files reviewed.
- 6 dialog-bearing files reviewed.
- Dashboard and login redesigned explicitly.
- Tenant, billing, subscription and access pages inherit the shared Admin theme for app bars, cards, forms, tables, dialogs, buttons, chips and page background.

## Shared implementation

- `lib/theme/admin_theme.dart`

The theme defines the approved MAWA red, deep navy typography, neutral page canvas, consistent borders, controls and enterprise dialog styling.

## Standards

- Use white cards on the light grey application canvas.
- Use red only for brand emphasis, primary actions and destructive states.
- Use deep navy for headings and primary text.
- Keep workcenter cards equal in height and use outcome-focused descriptions.
- Use status colours only for status meaning, not general decoration.
